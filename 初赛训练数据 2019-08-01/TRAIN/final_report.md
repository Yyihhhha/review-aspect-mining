| 指标 | 数值 |
|------|------|

| 数据质量评分 | 99.59 / 优秀 |

| 有效差评重灾区 Top3 | 包装(26.2%)、气味(19.6%)、服务(17.4%) |
| 可归类差评 P0 问题点 Top3 | 使用体验-质地问题(66个/39.5%)、包装-包装简陋/随意(22个/13.2%)、气味-香味过重/刺鼻(18个/10.8%) |

## 一、项目背景与目标

- **任务定义**：从化妆品电商评论中抽取观点四元组（属性特征 AspectTerms、观点词 OpinionTerms、属性种类 Categories、观点极性 Polarities）。
- **分析目标**：不止于抽取，进一步做**差评归因**，输出可落地的业务改进建议。
- **数据规模**：3229 条评论 / 6632 个四元组。

## 二、数据概览

- 数据质量评分 **99.59 / 100（优秀）**（见 cleaning_report.md）。
- 平均每条评论 2.05 个标签；隐式属性占比 **71.4%**（评论只表达观点、未点名属性）。

| 核心指标 | 数值 |
|----------|------|
| 评论数 / 四元组数 | 3229 / 6632 |
| 平均每条评论标签数 | 2.05 |
| 极性分布 | 正面 89.3%（5924）、负面 8.4%（556）、中性 2.3%（152） |
| 属性 Top3 | 整体 42.6%、使用体验 15.7%、功效 10.9% |
| 隐式属性占比 | 71.4% |

> **数据特征一句话**：小样本、极性极不平衡（正面压倒性）、属性长尾、以隐式表达为主。

## 三、核心发现

本项目沿“**表面好评 → 表达结构 → 吐槽落点 → 归因收敛**”一条主线展开：

1. **正面占比 89.3%，看似“用户很满意”——但这是假象**（步骤三，见图 4）；
2. 拆开隐式/显式发现：**隐式负面率 7.8% < 显式 10.0%**，即“表扬泛泛、吐槽点名”——用户笼统好评时不点名属性，真正不满时才精确制导（步骤四，见图 5）；
3. 再看观点词本身：**负面平均 3.11 字 > 正面 2.72 字**，“吐槽更具体、更长”，而吐槽集中在少数属性上（步骤五，见图 9）；
4. 收敛到问题点：单点“**使用体验-质地问题**”独占 **39.5%** 的可归类差评（步骤六，见图 16）。

> **升华**：这解释了“整体好评率 89%”与“用户总在吐槽”的体感差异——好评藏在笼统的“不错”“很好用”里，差评集中在具体的产品问题上。

## 四、整体分析（步骤三）

- **评论长度**（图 1）：均值 21.7 / 中位数 20 / 最大 69 / 最小 1 字，评论普遍简短，适合句级观点抽取。
- **每条评论四元组数量**（图 2）：1：1207 条（37.4%）、2：1114 条（34.5%）、3：562 条（17.4%）、4：242 条（7.5%）、5及以上：104 条（3.2%）；多数仅 1~2 个观点。
- **属性分布**（图 3）：头部集中，整体 42.6%、使用体验 15.7%、功效 10.9%，长尾属性（其他/成分/尺寸/新鲜度）占比 < 1%。
- **极性分布**（图 4）：正面 89.3% 占绝对多数，故图 4 改以“各属性负面率”定位重灾区。

## 五、属性维度深度分析（步骤四）

- **各属性负面率排序**（图 4）：有效重灾区（总提及≥80）为 包装 26.2%、气味 19.6%、服务 17.4%，分别是全局平均 8.4% 的 3.1 / 2.3 / 2.1 倍。
- **隐式 vs 显式**（图 5）：隐式负面率 7.8%（4735 个） < 显式 10.0%（1897 个）——点名属性时负面更集中。
- **属性共现结构**（图 6）：“整体”是绝对枢纽，Top3 共现对：使用体验+整体(459)、价格+整体(369)、功效+整体(318)。
- **隐式占比两极分化**（图 7/8）：高——真伪 100.0%、整体 99.6%、使用体验 91.0%；低——成分 0.0%、服务 4.7%、包装 6.7%。

## 六、情感与观点词分析（步骤五）

- **观点词长度**（图 9）：正面平均 2.72 字 vs 负面 3.11 字，负面表达更具体。
- **表扬 vs 吐槽 Top3**（图 10/11）：正面“不错、很好、很好用” vs 负面“不好用、不好、有点干”。
- **差评重灾区痛点词**（图 11/12）：包装看“没有/太随便了/破了”（做工与破损）、气味看“不是很喜欢/刺鼻/太香了”（难闻/过浓）、服务看“极差/敷衍了事/太慢”（态度差）。

## 七、差评归因专题（步骤五补 + 步骤六）

- **四属性最大差评子类**（占该属性负面比，图 15）：使用体验—质地问题 42.0%；包装—包装简陋/随意 43.1%；气味—香味过重/刺鼻 40.9%；服务—态度差/敷衍 46.7%。
- 关键词表覆盖率约 **63%**（见 bad_review_subcategory.md），剩余“其他”多为长尾个例。

- **帕累托·问题点维度**（图 16）：共 11 个问题点、合计 167 个可归类差评；前 **6** 个问题点（占问题点 54.5%）覆盖 **85.0%** 可归类差评。
- **帕累托·属性维度**（图 17）：前 **6** 个属性（使用体验、整体、功效、包装、气味、价格）覆盖 82% 全量差评。
- **判定**：不完全符合典型 80/20——头部单点“使用体验-质地问题”极度集中（39.5%），但累计到 80% 需覆盖过半问题点（54.5%），其余偏长尾。

> **百分比口径说明**：
> - 前 6 个问题点覆盖 85.0% 的**可归类差评**（167 个），占全量差评（556 个）的 **30.0%**；
> - “使用体验-质地问题”占 66/556 = **11.9%** 的全量差评；
> - 剩余约 70% 差评属于“其他/隐式负面/通用差评”，多为用户未明确表达具体原因的泛化吐槽，无法直接指向改进方向。本报告中“可归类差评”特指能匹配到具体子类的明确吐槽。

## 八、业务优化建议（P0/P1/P2）

- **投入产出比**：P0 集中在“产品配方”和“包装”两大环节，均属供应链侧可优化项，改进成本相对固定，却能覆盖 80%+ 的明确差评，ROI 最高。

**P0（解决 1 个即可消除 10%+ 可归类差评）**

- **使用体验-质地问题**（66 个，39.5%）→ 按肤质分型配方，针对“干/卡粉/浮粉/油/腻”定向改进；细化粉体粒径。
- **包装-包装简陋/随意**（22 个，13.2%）→ 改进外包装设计、增加缓冲防护材料、统一塑封/封口工艺。
- **气味-香味过重/刺鼻**（18 个，10.8%）→ 降低香精浓度，提供无香/淡香版本，改用更温和香型。
- **使用体验-效果问题**（17 个，10.2%）→ 补充功效实证、优化成分吸收，标注适用人群与致敏成分。

**P1（解决 1 个可消除 5%~10%）**

- 使用体验-肤感问题（10 个，6.0%）
- 气味-异味/不好闻（9 个，5.4%）

**P2（长尾）**：其余 5 个问题点，单个占比 < 5%，合计 15.0%，暂不单独投入资源。

## 九、项目局限与后续方向

- **局限**：
  - 正/负面词表为示例性词表，未做完整情感词典覆盖（疑似矛盾判定见 cleaning_report.md）；
  - 差评子类关键词覆盖率约 63%，剩余为长尾个例；
  - 隐式负面（如包装占该属性 13.7%）难以针对性归因；
  - 中性样本仅 2.3%，统计上不可靠。
- **后续方向**：用语义聚类替代词典匹配提升子类覆盖率；构造 BIO 序列标注样本进入建模阶段；结合时间维度做差评趋势分析。
